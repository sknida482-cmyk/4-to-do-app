# 📝 To-Do App

A simple and responsive **To-Do App** built using **HTML, CSS, and JavaScript**. The app allows users to add, complete, and delete tasks with an easy-to-use and responsive interface.

## ✨ Features

- ➕ Add new tasks
- ✅ Mark tasks as completed
- 🗑️ Delete tasks
- 📱 Fully responsive design
- 🎨 Clean and modern UI
- ⚡ Fast and interactive
- 💻 Works on desktop, tablet, and mobile

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
